# Reviewed CISO monitoring baseline

Frozen raw-target CQR prediction tables and source sidecars backing the published held-out results. They match the selected weather-free demo configuration; current-window exclusion and latest-per-target-hour selection remain monitor responsibilities. These files are held-out rolling-origin predictions, not calibration scores.

The publishing workflow packages these baselines with the existing main-reviewed demo model bytes. It trains no model and changes no selected pointer. Carbon coverage failed its published gate and is not certified nominal 80%. ERCO baselines remain unavailable until its independent pipeline and review complete.
