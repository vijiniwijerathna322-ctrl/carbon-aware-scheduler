# v0.2.0 research release draft

Status: prepared for scope approval; no tag or registry publication yet.

This release packages the verified forecasting/scheduling software and frozen
key-free CISO demo. It adds real ERCO evaluation, operational monitoring and
auditable automation, with measured limitations retained. It is a research
portfolio release, not a claim of production-ready interval calibration.

## Changes

- Config-driven region support and atomic snapshot/model-pointer regression checks.
- Weekly refresh, monitored alert issues, draft retraining candidates, reviewed
  bundle publication, dependency updates and tested container release workflow.
- Real ERCO paired forecasting comparison and scheduling replay.
- Reproducible portfolio figures, results, model card, datasheet, write-up,
  native API walkthrough and interview material.

## Measurements and decisions

ERCO median forecasts reduce MAE versus seasonal naive by 40.69% for demand and
38.32% for carbon, with G3 passing all horizon buckets. ERCO coverage is 74.72%
for demand (G4 fail) and 79.48% for carbon (G4 pass). Illustrative median-strategy
replay savings are 20.87%, compared with the 22.88% hindsight oracle.

Existing CISO demo selections are retained. CISO candidate carbon results
regress on the paired cohort, so draft PR 6 is not promoted. ERCO demand misses
G4, so draft PR 7 is not promoted. The earlier March 2025 180-day calibration
variant worsens coverage relative to 90 days; default parameters stay unchanged.

Live CISO refresh correctly reported input drift alerts and insufficient
post-fit coverage support, uploaded diagnostics, saved refreshed history and
opened issue 8. A green diagnostic collection job is not a healthy monitor claim.

## Limitations

Carbon is an average observed-generation lifecycle proxy, ignores imports and
unresolved fuels/storage, and does not estimate marginal or certified avoided
emissions. Historical evaluation assumes latest revisions and zero observation
latency. Replay jobs are equally weighted illustrative scenarios, not fleet data.
Conformal assumptions under dependence and drift remain material. Models have
not passed all production acceptance gates; ERCO has no approved deployment
bundle. Automatic candidate PR creation requires the repository Actions setting.
